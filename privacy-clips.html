개인정보처리방침

최종 업데이트: 2026년 5월 19일

📋 개요

Clips(이하 "앱")는 메뉴바에서 동작하는 클립보드 및 스크린샷 히스토리 앱입니다. 본 방침은 앱이 처리하는 데이터의 범위와 방식을 설명합니다.

💾 수집 및 저장하는 정보

앱은 아래 데이터를 기기 내부(로컬)에만 저장합니다.

  • 클립보드에 복사된 텍스트
  • 사용자가 직접 캡처한 스크린샷 이미지
  • 캡처 이미지에서 추출된 OCR 텍스트
  • 리딤 코드 등록 여부 (프로 버전 활성화 상태)
모든 데이터는 macOS의 앱 전용 저장소(userData)에 보관되며, 외부 서버로 전송되지 않습니다.

🚫 수집하지 않는 정보

  • 이름, 이메일, 전화번호 등 개인 식별 정보
  • 위치 정보
  • 기기 고유 식별자
  • 사용 통계 또는 분석 데이터
  • 광고 식별자

🌐 네트워크 사용

앱은 리딤 코드 검증 시에만 외부 네트워크에 접근합니다. 이 요청에는 입력한 코드 값 외의 개인 정보가 포함되지 않습니다. 그 외 모든 기능은 오프라인으로 동작합니다.

🔒 데이터 보안 및 접근

저장된 데이터는 오직 사용자 본인의 기기에서만 접근 가능합니다. 개발자는 어떠한 방법으로도 사용자 데이터에 접근할 수 없습니다.

👶 아동 보호

본 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

📝 방침 변경

본 개인정보처리방침은 변경될 수 있습니다. 중요한 변경이 있을 경우 앱 업데이트 노트 또는 본 페이지를 통해 사전에 안내드립니다.

Privacy Policy

Last updated: May 19, 2026

📋 Overview

Clips (the "App") is a menu bar app for managing clipboard and screenshot history. This policy explains what data the App handles and how.

💾 Information We Store

The App stores the following data locally on your device only.

  • Text copied to the clipboard
  • Screenshots captured by the user
  • OCR-extracted text from captured images
  • Redeem code activation status (Pro version)
All data is stored in the app's private macOS storage (userData) and is never transmitted to external servers.

🚫 Information We Do NOT Collect

  • Personal identifiers (name, email, phone number, etc.)
  • Location data
  • Device identifiers
  • Usage analytics or telemetry
  • Advertising identifiers

🌐 Network Access

The App accesses the network only to validate redeem codes. This request contains only the entered code — no personal information is included. All other features work entirely offline.

🔒 Data Security & Access

Stored data is accessible only on your own device. The developer has no ability to access your data by any means.

👶 Children's Privacy

This App is not directed at children under the age of 13, and we do not knowingly collect personal information from children.

📝 Changes to This Policy

This Privacy Policy may be updated from time to time. If significant changes are made, we will notify you through app update notes or this page in advance.
